# Collaborator Materials

This folder contains project-specific materials included for the pilot
handoff.

## `design_inputs/`

Descriptor CSVs supplied for the current oxidative esterification task.  TRACE
Lab currently uses the normalized project design space in
`runs/lab_projects/oxidative_esterification_demo/design_space.csv`; these
source CSVs are kept here so the design-space importer and future descriptor
features can be checked against the original inputs.

## `literature/`

Local PDFs used as scoped literature context.  They are not treated as oracle
outcomes.  Convert them into reviewed evidence cards through
`docs/collaborator_evidence_workflow.md` before relying on them for
recommendations.

## `background/`

Slides and the previous demo-result PDF for task context.  The old standalone
frontend runtime, executable, archive, and local environment files are
intentionally excluded from this handoff.
