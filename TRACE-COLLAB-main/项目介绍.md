# TRACE Lab 项目介绍

## 项目用途

这个项目是一个面向真实实验室的科学实验优化系统，名称为 TRACE Lab。它的核心目标是帮助研究人员在有限实验次数内，更高效地寻找更优的实验条件。

当前仓库中的示例项目是 `oxidative_esterification_demo`，用于氧化酯化反应条件优化，优化目标是提高产率 `yield`。

## 工作流程

TRACE Lab 采用 ask/tell 形式运行：

1. 在 `design_space.csv` 中定义可探索的实验变量和取值范围。
2. 系统根据已有实验结果和优化算法生成下一批实验推荐。
3. 实验人员根据推荐条件在真实实验室中完成实验。
4. 将实验结果写回 `observations.csv`。
5. 系统基于新结果继续生成下一轮推荐。

这个流程避免系统直接读取隐藏的真实结果，所有结果都必须通过实验人员提交进入系统。

## 当前示例项目

示例项目路径：

```text
runs/lab_projects/oxidative_esterification_demo
```

该项目包含：

- `project.yaml`：项目配置，包括反应名称、优化目标、批次大小、优化器和控制模式。
- `design_space.csv`：实验设计空间，定义添加剂、溶剂、TEMPO 衍生物、金属硝酸盐、配比、溶剂体积、温度等变量。
- `observations.csv`：实验观测结果表。目前只有表头，还没有实际实验结果。
- `evidence_cards.jsonl`：文献或领域知识证据卡，用于辅助推荐理由和决策记录。

## 核心功能

- 支持真实实验室批量实验推荐。
- 支持分类变量、离散数值变量、连续变量和固定条件。
- 可使用 `atlas` 或 `random` 优化器生成候选实验条件。
- 支持 agentic 控制模式，在优化器推荐基础上加入文献证据、候选筛选、推荐理由和决策追踪。
- 提供本地 Web UI 和 FastAPI 接口，用于加载项目、生成推荐、导出 CSV、提交实验结果和查看 trace。

## 启动方式

先创建并激活 Python 环境，然后安装依赖。README 推荐使用 Python 3.10。

启动本地 Web UI：

```bash
bash scripts/run_lab_api.sh \
  --projects-root runs/lab_projects \
  --host 127.0.0.1 \
  --port 8788
```

启动后打开：

```text
http://127.0.0.1:8788
```

加载示例项目：

```text
oxidative_esterification_demo
```

## 环境变量

如果要使用 agentic 控制模式，需要在 `.env` 中配置 OpenAI API key：

```text
OPENAI_API_KEY=你的 API key
```

如果不使用大模型控制器，可以在界面或命令行中选择 `bo_only` 模式，只使用优化器生成推荐。

## 当前项目状态

当前仓库已经包含氧化酯化 demo 的设计空间和文献材料，但 `observations.csv` 中还没有实际实验结果。因此它更像是一个可启动的实验推荐系统模板和演示项目，而不是一个已经完成的实验数据分析项目。
